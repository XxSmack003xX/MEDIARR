Connect your servers

No CORS headaches: the local Node server proxies every request, so you can use plain http://IP:PORT. Radarr default port 7878, Sonarr 8989. API keys live under Settings → General → Security in each app.

Actor / Director search — optional

Free from themoviedb.org → Settings → API. Needed for searching by person, year, or studio, and for recommendations.
Plex

Media server — optional, for health monitoring

See how to find your Plex token. Used to monitor uptime and build the health report.
Sign in on Plex's own page to capture your token automatically and pick your server — no manual token hunting.
Pick the address MEDIARR should use. If MEDIARR runs on the same network as Plex, the Local address is best.
Media

Downloads — optional, browse & play videos from a WebDAV server or a folder on this machine

An absolute path readable by the MEDIARR process. Browsing is locked to this folder — users can't reach anything above it. In Docker/LXC the folder must be mounted inside the container.
Leave blank to browse from the top. Videos here are listed under the Downloads button; each download counts against the user's daily limit.
Recommended is the first option: files download straight from the WebDAV server and your browser handles the login once per session, so credentials never appear in a link. MEDIARR still authorizes and counts each download.
Requires ffmpeg installed on the server. Only re-encodes what the browser can't play; you can also toggle it per video in the player.
Appearance

Login screen theme

Shown on the login page for everyone. Changes apply next time the login screen appears.
Auto add

Auto add pacing

Pace of the queue — one item per interval so your indexers aren't hammered. Decimals allowed (0.5 = 30 seconds). 0 = no delay.
Auto add checks each title's runtime and skips anything shorter — good for filtering out shorts, specials and featurettes. 0 = add everything.
⚡ Auto add all loads every result first, then adds what you don't already have. It runs on the server, so you can close the page.
SAB

SABnzbd — optional, shows a Queue button to everyone

SABnzbd → Config → General → API Key. Everyone signed in can view the queue and history; nobody can change anything from here.
Alerts

Notifications — get told when things happen

Paste the webhook URL from Discord → Channel settings → Integrations.
RSS

Release feeds — watch feeds and add anything you don't have

One per line. MEDIARR reads each release name, works out the title, and adds it if you don't already have it. TV releases add the whole show, not just that episode.
Minimum 10.
A safety cap so a busy feed can't flood your indexers.
0 = no limit.
